# DeepSeek 划词助手（追问 + 翻译）

一个基于 Chromium 内核（Chrome / Edge / 360 / 夸克等）的浏览器扩展：在**网页版 DeepSeek** 的对话里划词，
就地弹出两个按钮 —— 点「追问」把选中的内容带到一个**新对话**里继续问；点「英文」在按钮旁边弹出一个**小展示框**，
显示**英文读音**和**中文释义**。

```
选中文字 ──► [ 💬 追问 | 译 英文 ] ──┬─► 追问：小框里输入问题 → 当前标签页开新对话并自动发送
                                    └─► 英文：小框里显示 /音标/ + 🔊 发音 + 中文释义 + 例句
```

---

## 一、安装（3 步，约 1 分钟）

### 方式 A：一键安装助手（推荐）

1. 双击文件夹里的 **`一键安装.bat`**（若被 SmartScreen 拦截，选「更多信息 → 仍要运行」）。
2. 脚本会自动：把插件目录复制到剪贴板 → 打开浏览器的扩展管理页。
3. 在扩展管理页里：
   - 打开右上角的 **开发者模式 / 开发人员模式** 开关；
   - 点 **加载已解压的扩展程序 / 加载解压缩的扩展**；
   - 在文件夹选择框里按 **Ctrl+V** 粘贴路径，回车确定。

### 方式 B：手动安装

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）。
2. 打开右上角 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择本文件夹（就是含 `manifest.json` 的那一层）。
4. 打开 <https://chat.deepseek.com>，选中任意一段文字即可看到按钮组。

> 首次安装后如果页面已经开着，刷新一次即可。
> 本插件不需要账号、不需要付费 Key，卸载就在扩展管理页点「移除」。

## 二、怎么用

| 操作 | 结果 |
| --- | --- |
| 在对话里**划选一段文字** | 选区上方浮出 `💬 追问` 和 `译 英文` 两个按钮 |
| 点 **💬 追问** | 小展示框里自动带上被选中的原文（蓝色引用条），输入问题后按 `Enter` 或点「新对话追问」 |
| 发送后 | **就在当前标签页**开一个全新对话（等价于点左上角「开启新对话」，不会堆一串新标签页），原文以引用块 + 你的问题**自动发出**，不用再点一次发送 |
| 点 **译 英文** | 小展示框就地出现：单词 + `/音标/` + `🔊 真人发音` + **中文释义** + 词性 + 例句 |
| 框里按 `Esc` / 点 `×` / 点页面别处 | 关闭小展示框 |

细节：

- 追问框里有 4 个快捷短语（解释这段话 / 翻译成中文 / 举一个例子 / 继续展开讲讲），可在设置里改。
- 追问框里 `Enter` 发送、`Shift+Enter` 换行。
- **自动发送做了三重保险**：① 借助 `?q=` 让 DeepSeek 自己发；② 页面脚本就绪后补一次「自动填入 + 回车」；③ 万一回车没被页面接受，会提示你手动按一次 Enter。
- 自动填入前会先看输入框：**如果你正在输入别的内容，它绝不会覆盖**。
- 发音按钮优先播放词典的真人发音；没有音频时自动退回系统语音朗读。
- 划选的是单词就按单词处理，划选的是句子/短语就按整句翻译处理。
- 页面是深色模式时，展示框会自动跟随深色配色。

## 三、翻译来源（自动回退，任何一条通就行）

点「英文」后，扩展按**选中内容的形态**自动选路线，再按下面的顺序依次尝试，**哪条先成功就用哪条**：

| 选中的是 | 结果 |
| --- | --- |
| **单个单词**（`Phase`、`loop`、`clock` —— 大小写、连字符都不影响） | `/音标/` + 🔊 发音 + **中文释义** |
| **短语 / 句子**（`Enable the internal clock source`） | **整句中文翻译** |

> 单词是「**先出中文、再补音标**」：中文源通常几百毫秒就回；音标源（dictionaryapi）往往要 1.5 秒以上，
> 所以它**用独立的 1.8 秒预算**去补，**到点会真正取消那个请求**（不是干等），绝不拖慢主结果。
> 连不上的源会被**临时跳过 10 分钟**，不会每次都白等超时。
> 想调这个预算：设置里没有暴露，改 `src/lib/translate.js` 里的 `PHONETIC_TIMEOUT_MS`，
> 或在 `options` 里传 `phoneticTimeout`（毫秒）。

翻译来源（自动回退）：

1. **内置离线词库**（约 230 个高频词与常见技术词）—— 零延迟、不联网，`phase` / `clock` / `translation` 这类词秒出。
2. **有道词典公开接口**（`dict.youdao.com/jsonapi`）—— 免 Key，**国内可直连**，带音标、义项最全（实测 ~400ms）。
3. **百度翻译开放平台官方 API**（填了 APPID + 密钥就走它）—— 你自己的额度，最稳（实测 ~360ms）。
4. **百度词典公开接口**（`fanyi.baidu.com/sug`）—— 免 Key，最快（实测 ~300ms）。
5. **百度翻译公开接口**（`fanyi.baidu.com/transapi`）—— 免 Key，整句用；常因风控返回 `errno:1022`（可忽略）。
6. **MyMemory**（免 Key，整句翻译）—— 实测较慢（1.7 秒+），排在中文源之后。
7. **dictionaryapi.dev** —— 免 Key，提供音标 + 真人发音音频 + 英文释义、例句；只用于**补充**，不挡主结果。
8. **Google 词典** —— 免 Key，实测 700ms+，同样只做兜底。
9. **你自配的接口**（OpenAI 兼容）—— 单词和句子都能处理，最灵活。

> 上面的顺序是**按你机器上的实测耗时和质量排的**（依据设置页诊断表）：
> 有道/百度/百度官方都在 300～400ms，所以**优先走它们**；MyMemory 和 Google 慢一倍以上，放后面兜底。
> 单词固定是「先中文、后音标」，中文一出来就立刻收尾。

> **不确定哪个能用？** 设置页最上方有一个 **「检测可用翻译源」** 按钮，点一下扩展会挨个真跑一遍，
> 直接列出每个源是「✓ 可用 / △ 能连上但没返回 / × 不可用」以及原因和耗时。
> 你不用猜，也不用读源码。

> ⚠️ **「× 不可用」可能是权限问题，不一定是网络**：扩展在后台发跨域请求，必须在 `manifest.json` 的
> `host_permissions` 里声明域名，否则会被浏览器直接拦掉。本项目已声明上面列出的所有域名；
> 你自己填的「自定义接口」域名不在此列，保存时需要用弹窗单独授权。
> `tools/verify.js` 会检查「代码里用到的域名是否都已声明」，避免再犯这个错。

几个细节：

- 大小写完全不影响识别：`Phase` 就按 `phase` 查，**不会**被当成拼写错误。
- 「你是不是想查 xxx」这个纠错提示只在**真的很像打错**时才出现（编辑距离 ≤ 2 且不超过词长的 30%），
  并且至少 5 个字母 —— 所以 `Phase` 不会再被建议成 `has` 了。
- 选中内容像代码片段（含 `< > { } ; \` 之类）时，不再丢给整句翻译（那只会返回废话），而是**按其中的单词逐个给释义**。
- 连字符组合词（`phase-locked`）会拆成 `phase` + `lock` 给各段意思。
- 内置词库只做**兜底**：只要在线源能给出更好的释义，就用在线结果。

## 四、设置

在扩展管理页点本插件的「详情 → 扩展程序选项」，或直接右键扩展图标 → 选项：

- **检测可用翻译源**：最上面那个按钮。挨个真跑一遍，告诉你哪些源在你网络下能用（含原因和耗时）。
  失败的源会附上「**查看原始返回** → 复制这段内容」；百度官方接口的常见错误码
  （54001 签名错误、52003 未授权、54004 余额不足、58000 IP 非法…）已直接翻译成人话。
- **导出调试日志**：把最近 60 条「请求 → 返回」原文（含 HTTP 状态码和响应体）导出并自动复制到剪贴板。
  遇到"扣了额度但没结果"这类问题时，点它把日志发我即可定位，不用来回猜。
  日志会写进浏览器的 session 存储，所以后台被回收/重启后仍然导得出来。
- **优先使用的来源**：自动 / 只用离线词库 / 只用免费在线词典 / 只用自定义接口。
  > 注意：**这里只决定"自定义接口"要不要参与，不会关掉你在下面填过的百度密钥**。
  > 百度密钥是你自己的额度，填了就一直优先使用；选了「只用自定义接口」但没配好自定义接口时，也会兜底到百度密钥。
- **百度翻译开放平台（可选，最稳）**：在 <https://fanyi-api.baidu.com> 注册，管理控制台 → 开发者信息里拿
  **APPID** 和**密钥**（注意是「密钥」，不是登录密码），填进来即可。
  免费额度：通用文本翻译标准和高级版每月 5 万字符、尊享版 100 万字符。
  填了以后无论上面「优先使用的来源」怎么选，都会优先走它。
  > 如果你申请的是控制台里「**API Key 管理**」那个 Key，那属于**大模型文本翻译**，是另一套鉴权；
  > 当前版本走的是**通用文本翻译**（APPID + 密钥），两者别混填。
- **自定义接口**：填 OpenAI 兼容地址（如 `https://api.deepseek.com/chat/completions`）、API Key、模型名，
  以及返回 JSON 的提示词（留空用默认）。默认提示词要求模型返回：
  ```json
  {"phonetic":"音标","meaning":"中文释义","examples":[{"en":"例句","zh":"译文"}],"partOfSpeech":"词性","note":"备注"}
  ```
  Key 只保存在你自己浏览器的同步存储里，不会发给除该接口以外的任何地方。
- **追问快捷短语**：每行一个，最多 8 个。

> 想让自定义接口生效：保存设置（或点「测试这个接口」）时 Chrome 会弹出「扩展程序请求访问 xxx 的权限」，
> 点允许即可（插件按需只为这一个域名申请权限，不会一上来就要所有网站权限）。
> 接口本身需要支持浏览器跨域（CORS）。

### 拿到 DeepSeek 官方接口地址和 Key 的最短路径

1. 打开 <https://platform.deepseek.com> 注册/登录（**这是开发者平台，和聊天网站 chat.deepseek.com 不是一个站**）；
2. 左侧「API keys」→ 新建并复制 Key（只显示一次）；
3. **先去「充值 / Top up」充一点余额**，否则调用会返回 402（余额不足）；
4. 设置页填：地址 `https://api.deepseek.com/chat/completions`，模型 `deepseek-chat`，粘上 Key；
5. 点 **测试这个接口** —— 它会用单词 `translation` 试跑一次，直接告诉你成功（带音标/释义）还是失败（带原因，例如 401 / 402 / CORS / 超时）。
6. 看到 ✓ 再点 **保存设置**。回到 DeepSeek 页面刷新即可。

不要填聊天网站的地址（`chat.deepseek.com` 不是 API，会 404）。

## 六、常见问题

> 排障优先看 **[配置备忘.md](配置备忘.md)**：里面有各源实测耗时/质量、密钥怎么填、
> 哪些"报错"其实可以忽略、出问题先看日志哪一行。

**Q：划词后没反应？**
刷新页面；确认扩展已启用且当前页面是 `chat.deepseek.com`；再确认选中的文字长度 ≥ 2 个字符。

**Q：追问后新对话里没有自动发送？**
不同版本的 DeepSeek 对 `?q=` 参数的处理不一样，所以扩展做了三重保险：URL 参数 → 脚本就绪后自动填入并回车 →
若回车仍未被接受则弹提示。真遇到没自动发的情况，内容一定已经在输入框里了，手动按一次回车即可。
（自动填入只在输入框为空时执行，不会覆盖你正在打的内容。）

**Q：点「英文」提示查询失败？**
先在设置页点 **「检测可用翻译源」**，看哪些源是「✓ 可用」。然后：

- 有可用的 ← 直接刷新 DeepSeek 页面重试；
- 全部「× 不可用」← 在你网络下公开接口都被拦了，请填百度翻译开放平台的 APPID/密钥，或配置自定义接口。

**Q：免费的公开接口能用多久？**
`fanyi.baidu.com`、`dict.youdao.com` 这些是公开接口，不是官方承诺的 API，可能随时改格式或限流。
所以扩展里做了多源回退 + 诊断按钮；要长期稳定，用百度开放平台（有免费额度）或你自己的接口。

**Q：会看到我在 DeepSeek 里的对话内容吗？**
不会。扩展只读取你**主动划选**的那一小段文字，且只把它发给上面列出的词典/翻译接口，本地不留存记录。

**Q：升级后按钮不出现了？**
到扩展管理页点一下本插件的「刷新」，然后刷新 DeepSeek 页面。

## 七、开发者备注

- 全程使用 **Shadow DOM + `all: initial`**，样式与页面完全隔离，不会污染 DeepSeek 的界面。
- 网络请求全部走 Service Worker，绕开页面 CORS 限制；带 9 秒超时与结果缓存。
- 划词按钮组只在选区上方/下方浮动，滚动与窗口尺寸变化时自动重新定位；`Esc` 可关闭。
- 针对复杂问题提问或学习时，建议置顶主任务，避免过多追问将主任务掩盖。

自检命令（需要 Node.js）：

```bash
node tools/verify.js        # 清单引用、模块导出、词库条目、图标尺寸    → 全部通过
node tools/check.js         # 翻译逻辑（多源回退 / 死源冷却 / 音标预算 / 边界） → 41/41
node tools/cn-source.js     # 百度/有道解析 + MD5 对拍 + 优先级顺序 + 错误码 → 35/35
node tools/background-flow.js  # 后台 worker：加载 / 应答 / 诊断 / 日志持久化 → 27/27
node tools/smoke.js         # 用 DOM 打桩跑真实 ui.js 主链路            → 32/32
node tools/content-flow.js  # 划词追问 → 当前页开新对话 → 自动发送      → 14/14
python tools/make_icons.py   # 需要改图标时重新生成
```

`test-harness.html` 是界面预览页（用假数据驱动真实界面，不依赖浏览器扩展环境）：
浏览器打开后可以点四个按钮分别预览按钮组、翻译框、追问框、拼写纠错提示；
网址后加 `?shot=1/2/3/4` 可直接看到对应状态。
